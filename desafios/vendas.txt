A intenção é alterar as próprias posições para obter [20, 40, 60].

✓ Caso resolvido · +100 pontos.
Para alterar o array, o código precisa escrever em valores[i]. Depois do percurso, as posições contêm 20, 40 e 60.

for (int i = 0; i < valores.length; i++) {
  valores[i] = valores[i] * 2;
}
